# Data

Carpeta destinada a almacenar los datos utilizados durante el proyecto Banco Atlas.

## Contenido

Esta carpeta contiene los datasets de trabajo empleados para el análisis de clientes, campañas comerciales y riesgo financiero.

## Uso de los datos

Los datos se utilizan como base para:

- Análisis del perfil de cliente
- Evaluación de campañas de marketing
- Estudio de riesgo crediticio
- Preparación de métricas y visualizaciones

## Criterios de organización

- Mantener separados los datos originales y los datos transformados cuando sea necesario.
- Evitar duplicados o versiones intermedias innecesarias.
- Utilizar nombres de archivo claros y consistentes.
- No incluir archivos temporales, pruebas locales o datos no validados.

## Nota

Esta carpeta funciona como fuente de información del proyecto. Cualquier transformación relevante debe quedar documentada en los notebooks o scripts correspondientes.
