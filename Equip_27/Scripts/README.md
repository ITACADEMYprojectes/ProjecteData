# Scripts

Carpeta destinada a almacenar los notebooks y scripts utilizados para el análisis del proyecto Banco Atlas.

## Contenido

Esta carpeta recoge el trabajo técnico desarrollado por los distintos departamentos del proyecto:

- Perfil Cliente
- Marketing y Comunicación
- Finanzas y Riesgos Crediticios

## Objetivo

Centralizar el código utilizado para explorar, transformar y analizar los datos, asegurando que el proceso sea trazable, ordenado y fácil de revisar.

## Criterios de organización

- Utilizar nombres de archivo claros y descriptivos.
- Mantener los notebooks limpios y con una estructura comprensible.
- Documentar los pasos principales del análisis.
- Evitar archivos temporales, pruebas sueltas o versiones duplicadas.
- Guardar los resultados finales en la carpeta `Results`.

## Nota

Los scripts incluidos en esta carpeta sirven como soporte técnico del análisis y permiten revisar cómo se han obtenido los principales resultados presentados.
